# Histórico de versões / Changelog

## [1.1.0] — 2026-10-26

- Barra de formatação nos textos do certificado: negrito, itálico, sublinhado, tamanho da fonte por trecho e limpar formatação / Formatting toolbar for certificate texts: bold, italic, underline, per-passage font size and clear formatting;
- Controle do tamanho da fonte do nome do participante / Participant name font size control;
- Texto colado entra sem formatação externa / Pasted text is inserted without external formatting.

## [1.0.0] — 2026-10-23

Primeira versão pública / First public release.

- Interface bilíngue português/inglês com seletor de idioma (PT/EN), parâmetro `?lang=` na URL e memória da última escolha / Bilingual Portuguese/English interface with language switcher, `?lang=` URL parameter and remembered choice;
- Textos padrão do certificado acompanham o idioma enquanto não forem editados / Default certificate texts follow the language until edited;
- Certificado, verso, nomes de arquivos e tabela de registros gerados no idioma selecionado / Certificate, back page, file names and registry generated in the selected language;
- PDFs com compressão JPEG (cerca de 240 KB por certificado, ante cerca de 19 MB na versão interna anterior) / JPEG-compressed PDFs (about 240 KB per certificate, down from about 19 MB in the previous internal version);
- Número de registro incluído no nome do arquivo PDF / Registration number included in the PDF file name;
- Importação aceita as colunas NOME, NAME, ALUNO ou STUDENT, e arquivos CSV / Import accepts NOME, NAME, ALUNO or STUDENT columns, and CSV files;
- Pré-visualização centralizada / Centered preview;
- Textos digitados pelo usuário são exibidos com segurança (escape de HTML) / User-typed text is safely displayed (HTML escaping).
